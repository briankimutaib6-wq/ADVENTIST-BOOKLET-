# Adventist Booklet

A small, multilingual reading site about Christ and classic Adventist books.

## Contents

- **Books:** introductory reading pages for *Steps to Christ*, *The Great Controversy*, and *The Desire of Ages*.
- **Languages:** English, Kiswahili, and Kalenjin starter pages.
- **Website:** open [`index.html`](index.html) locally, or enable GitHub Pages to publish it.
- **Cover artwork:** [`assets/cover.svg`](assets/cover.svg). Replace it with a properly licensed image if desired.

The book pages are summaries and reading guides, not complete book texts. Add or link to full texts only when you have verified the translation and usage rights.
